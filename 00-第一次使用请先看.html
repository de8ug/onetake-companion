① 先把压缩包解压出来

Mac：双击下载的 ZIP。Windows：右键 ZIP →「全部解压」。打开解压后的 onetake-workbench 文件夹，建议把整个文件夹放到「文稿」或其他固定位置。

不要直接在压缩包里运行，也不要只把启动文件单独拖出来。启动文件需要和其他文件放在一起。

② 首次使用，检查运行环境

当前是开源启动包，还需要安装 Node.js 22 或更新版本，以及 FFmpeg / ffprobe。启动器会检查，不会替你自动安装软件。

  1. 从 Node.js 官网下载适合自己电脑的安装程序，完成安装。
  2. 按照 FFmpeg 下载页对应的 macOS 或 Windows 指引安装 FFmpeg，确保同时包含 ffprobe。
  3. 安装后重新打开启动文件。若仍提示找不到工具，查看下面的「启动遇到问题」。

官网 ZIP 已包含工作台所需的 JavaScript 依赖，不需要再下载源码、运行 npm 或安装编程软件。Node.js 和视频处理工具尚未内置；如果不熟悉安装，可先使用 OneTake 项目广场准备和录制。

③ Mac：双击这个文件

Mac 双击这里启动 OneTake.command

打开后会出现一个启动窗口，检查通过后自动打开浏览器。看到工作台页面，就可以开始了。

提示「Apple could not verify…」怎么办？

这份开源启动包尚未经过 Apple 签名、公证。系统无法验证它，不等于已经检测出恶意软件，也不能据此保证文件安全。

  1. 先确认下载来源是 onetake.show 官网或 de8ug/onetake-companion 官方仓库。关闭拦截提示。
  2. 打开苹果菜单 →「系统设置」→「隐私与安全」，向下找到刚才启动文件的拦截记录。
  3. 确认显示的文件名后，点击「仍要打开 / Open Anyway」，按系统提示验证并打开。旧版的名字是 start.command。

如果没有「仍要打开」，再双击一次启动文件后查看；受单位管理的电脑可能不允许这项操作。若提示「将损坏电脑」或明确检测到恶意软件，请停止运行，不要按上述步骤放行。

不需要关闭整台电脑的安全检查，也不需要移除整个下载目录的安全标记。Apple 官方说明

③ Windows：双击这个文件

Windows 双击这里启动 OneTake.cmd

先「全部解压」，再双击。会出现启动窗口；检查通过后浏览器自动打开。Windows 可能显示来源或安全检查提示，请核实来源和文件，不要关闭系统防护。旧版入口 start.cmd 也可继续使用。

④ 看到工作台，接下来做什么？

  1. 可以直接手动创建工程，也可以在「我的模型」保存自己的 API Key，再按主题生成稿件。
  2. 保存工程后，点击「OneTake 导入」，或把下载的工程导入手机。
  3. 网页需要连接工作台时，使用启动时提供的配对码。配对码和 API Key 都不要发给其他人。网页高级粗剪与封面导出需要有效 PRO。

浏览器没自动弹出？启动成功后，在浏览器地址栏输入 http://127.0.0.1:3010/。关掉网页不等于停止后台工作台。

启动遇到问题

提示缺少 Node.js、FFmpeg 或 ffprobe

安装对应工具后重开启动窗口。即使只准备稿件，当前启动器也会检查视频工具。完整 ZIP 不需要 npm ci；通过 Git 下载源码才需要安装依赖。

熟悉终端的用户可以检查：node --version、ffmpeg -version、ffprobe -version。它们需要可从系统命令行访问（PATH）。如果报「找不到命令」，需要完成安装或工具路径设置。

升级后页面还是旧版

先保存正在修改的稿件。旧工作台可能仍在后台运行；如果不熟悉如何停止，可以重启电脑，再从新解压的文件夹启动。不要重复启动多个版本。

稿件、视频和模型设置会不会被删掉？

工程通常保存在「文稿 / Documents」里的「OneTake视频工作台」。模型与配对设置单独保存在你的用户目录。更换程序文件夹不会自动清空这些资料；不要删除自己的工程或设置目录。旧视频仍在原来保存的位置。

更多操作：同目录的 USER_GUIDE.zh-CN.md，或 在线帮助。反馈错误时只发送错误文字，不要发送 Key、配对码或私人视频。
